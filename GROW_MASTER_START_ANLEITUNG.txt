🚀 APP LOKAL TESTEN - 3 METHODEN

📌 METHODE 1: Mit Python (Empfohlen - einfachste Methode)

   Öffne Terminal/Eingabeaufforderung im App-Ordner:

   cd grow-master-app/www
   python3 -m http.server 8000

   Dann öffne im Browser:
   http://localhost:8000

📌 METHODE 2: Mit Node.js

   npx http-server -p 8000

   Dann öffne im Browser:
   http://localhost:8000

📌 METHODE 3: Direkt im Browser (ohne Server)

   1. Öffne den Ordner: grow-master-app/www/
   2. Doppelklick auf: index.html
   3. Die App öffnet sich im Browser

   ⚠️ HINWEIS: Ohne Server funktionieren manche PWA-Features
      (wie Service Worker) nicht. Für volles Testen nutze
      Methode 1 oder 2.

🆘 PROBLEME?

Problem: "python3 command not found"
Lösung: Installiere Python von python.org
         Oder nutze: python -m http.server 8000

Problem: "Port 8000 already in use"
Lösung: Nutze einen anderen Port: python3 -m http.server 8080

Problem: "Service Worker registration failed"
Lösung: PWAs brauchen HTTPS oder localhost
        → Nutze Python/Node Server (nicht file://)
