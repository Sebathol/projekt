## 📦 Was ist enthalten?

Eine **vollständige, kommerzielle Desktop-Anwendung** zum Anzeigen von PDF-Dateien, komplett vorbereitet für den Verkauf und Vertrieb!

## 🚀 Schnellstart

### Option 1: ZIP-Datei nutzen (Empfohlen!)

```bash
# ZIP entpacken
unzip PURE-PDF-VIEWER-KOMPLETT.zip -d pure-pdf-extracted

# In Verzeichnis wechseln
cd pure-pdf-extracted

# Dependencies installieren
npm install

# App testen
npm start
```

### Option 2: Ordner nutzen

```bash
cd pure-pdf-app
npm install
npm start
```
