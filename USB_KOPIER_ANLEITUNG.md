## 📋 MANUELLE METHODE (wenn Script nicht funktioniert)

### Windows - Schritt für Schritt:

**1. Projekt-Ordner öffnen:**
```
Drücke: Windows-Taste + R
Gib ein: %USERPROFILE%\projekt
(oder navigiere zu /home/user/projekt)
```

**2. Alle Dateien markieren:**
```
Drücke: Strg + A
```

**3. Kopieren:**
```
Drücke: Strg + C
```

**4. USB-Stick öffnen:**
```
Öffne "Dieser PC"
Doppelklick auf "D:\"
```

**5. Neuen Ordner erstellen:**
```
Rechtsklick → Neu → Ordner
Name: simple-weather-app
```

**6. In Ordner reingehen:**
```
Doppelklick auf: simple-weather-app
```

**7. Einfügen:**
```
Drücke: Strg + V
Warte, bis alles kopiert ist
```

**8. Fertig! ✅**

## 🆘 PROBLEM-LÖSUNG:

### "Zugriff verweigert"
```
→ USB-Stick ist schreibgeschützt
→ Rechtsklick auf D:\ → Eigenschaften
→ Häkchen bei "Schreibgeschützt" entfernen
```

### "Nicht genug Speicherplatz"
```
→ USB-Stick ist voll
→ Projekt braucht nur ~1 MB
→ Platz schaffen oder anderen Stick nutzen
```

### "Dateien nicht gefunden"
```
→ Projekt-Ordner falsch
→ Prüfe Pfad: /home/user/projekt/
→ Oder nutze Datei-Explorer-Suche
```

### "Script funktioniert nicht"
```
→ Nutze manuelle Methode (siehe oben)
→ Oder: ZIP-Datei nutzen
→ weather-app-complete.zip auf USB kopieren
→ Dann auf USB entpacken
```
