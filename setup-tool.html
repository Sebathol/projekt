❓ Hilfe & Anleitungen


                    

                        
🎯 Was ist dieses Tool?

                        

                            Dieses Setup-Tool hilft dir dabei, API-Keys sicher in deine Weather App zu integrieren.
                            Du kannst mehrere API-Keys verwalten, zwischen ihnen wechseln und automatisch den
                            richtigen Code generieren lassen.
                        

                    


                    
📋 Schritt-für-Schritt Anleitung:


                    

                        
1️⃣ API-Key besorgen

                        
WeatherAPI.com (Empfohlen):

                        
    
                            
  1. Gehe zu weatherapi.com/signup
    2. 
                            
  2. Registriere dich (kostenlos)
    3. 
                            
  3. Bestätige deine E-Mail
    4. 
                            
  4. Login → Dashboard
    5. 
                            
  5. Kopiere deinen API-Key (beginnt mit a1b2c3...)
    6. 
                        

                    


                    

                        
2️⃣ API-Key in diesem Tool speichern

                        
    
                            
  1. Wechsle zum Tab "API-Keys verwalten"
    2. 
                            
  2. Wähle "WeatherAPI.com"
    3. 
                            
  3. Gib eine Bezeichnung ein (z.B. "Production")
    4. 
                            
  4. Füge deinen API-Key ein
    5. 
                            
  5. Klicke auf "API-Key speichern"
    6. 
                        

                    


                    

                        
3️⃣ Code generieren & implementieren

                        
    
                            
  1. Wechsle zum Tab "Code generieren"
    2. 
                            
  2. Wähle deinen gespeicherten API-Key
    3. 
                            
  3. Klicke auf "Code generieren"
    4. 
                            
  4. Klicke auf "Code kopieren"
    5. 
                            
  5. Öffne script.js
    6. 
                            
  6. Ersetze den Code ab Zeile ~5
    7. 
                            
  7. Speichere die Datei
    8. 
                        

                    


                    

                        
4️⃣ Testen

                        
    
                            
  1. Öffne index.html im Browser
    2. 
                            
  2. Gib eine Stadt ein (z.B. "London")
    3. 
                            
  3. Klicke auf "Suchen"
    4. 
                            
  4. ✅ Wetterdaten sollten angezeigt werden!
    5. 
                        

                    


                    

                        
🔐 Sicherheitshinweise:

                        
    
                            
  • Teile niemals deine API-Keys öffentlich
    • 
                            
  • Committe API-Keys nicht in Git (außer für Development)
    • 
                            
  • Für Production: Verwende Backend oder Umgebungsvariablen
    • 
                            
  • Rotiere Keys regelmäßig bei verdächtiger Aktivität
    • 
                            
  • Nutze separate Keys für Development/Production
    • 
                        

                    


                    
🔄 API-Key wechseln:

                    

                        Um zwischen verschiedenen API-Keys zu wechseln (z.B. von Test auf Production):
                    

                    
    
                        
  1. Tab "Code generieren" öffnen
    2. 
                        
  2. Anderen API-Key auswählen
    3. 
                        
  3. Neuen Code generieren und kopieren
    4. 
                        
  4. In script.js ersetzen
    5.
