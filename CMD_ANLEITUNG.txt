    SO KOPIEREN SIE DIE APP MIT CMD AUF USB-STICK
═══════════════════════════════════════════════════════════════

📋 METHODE 1: AUTOMATISCHES SCRIPT (EMPFOHLEN)
──────────────────────────────────────────────────────────────

1. Drücken Sie: Windows-Taste + R
2. Tippen Sie: \\wsl.localhost\Ubuntu\home\user\projekt
3. Drücken Sie: Enter
4. Doppelklick auf: KOPIERE_APP_AUF_USB.bat
5. FERTIG! Das Script kopiert alles automatisch auf D:\


═══════════════════════════════════════════════════════════════

💻 METHODE 2: MANUELL MIT CMD
──────────────────────────────────────────────────────────────

1. Drücken Sie: Windows-Taste + R
2. Tippen Sie: cmd
3. Drücken Sie: Enter

4. Kopieren Sie diese Befehle (jeweils Enter drücken):

   mkdir D:\simple-weather-app

   copy "\\wsl.localhost\Ubuntu\home\user\projekt\SIMPLE-WEATHER-APP-KOMPLETT.zip" D:\simple-weather-app\

   explorer D:\simple-weather-app

5. FERTIG! Die ZIP-Datei ist jetzt auf D:\


═══════════════════════════════════════════════════════════════

🚀 SCHNELLSTE METHODE: DIREKT AUS WSL
──────────────────────────────────────────────────────────────

1. Öffnen Sie: Ubuntu (WSL) Terminal
2. Tippen Sie:

   cp SIMPLE-WEATHER-APP-KOMPLETT.zip /mnt/d/

3. FERTIG!


═══════════════════════════════════════════════════════════════

❓ PROBLEME?
──────────────────────────────────────────────────────────────

Falls D:\ nicht existiert:
- Öffnen Sie Windows Explorer
- Schauen Sie welcher Laufwerksbuchstabe Ihr USB-Stick hat
- Ändern Sie "D:" im Script zu Ihrem Buchstaben (z.B. "E:" oder "F:")
