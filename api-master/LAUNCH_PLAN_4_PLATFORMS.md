## 🎯 Schritt-für-Schritt: Vercel Deployment (HEUTE!)

### ⏱️ Dauer: 30 Minuten

#### Schritt 1: Vercel Account (2 Min)
```bash
1. Gehe zu: https://vercel.com
2. Sign up with GitHub
3. Authorisiere Vercel
```

#### Schritt 2: Projekt importieren (5 Min)
```bash
1. "Add New Project"
2. Wähle GitHub Repository
3. Framework: "Vite" auswählen
4. Root: "frontend" eintragen
```

#### Schritt 3: Umgebungsvariablen (10 Min)
```bash
Settings → Environment Variables:

VITE_API_URL = https://api-master-backend.vercel.app/api
VITE_SOCKET_URL = https://api-master-backend.vercel.app
VITE_APP_ENV = production
```

#### Schritt 4: Backend deployen (10 Min)
```bash
1. Neues Projekt: Backend
2. Framework: "Other"
3. Build Command: "npm install"
4. Output Directory: "."

Environment Variables:
NODE_ENV = production
DATABASE_URL = [Ihre PostgreSQL-URL]
JWT_SECRET = [Ihr Secret]
[... alle anderen aus .env]
```

#### Schritt 5: Custom Domain (optional, 3 Min)
```bash
Settings → Domains:
1. Add Domain: "api-master.com"
2. Configure DNS (Nameservers von Vercel)
3. Warten auf Propagation (1-24h)
```

#### Schritt 6: Testen! ✅
```bash
https://your-app.vercel.app
```
