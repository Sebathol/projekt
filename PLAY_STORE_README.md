## 🛠️ Nächste Schritte (Reihenfolge)

### Phase 1: Asset-Erstellung (2 Wochen)
1. **Icons designen** (Figma/Photoshop)
   - Nutze bestehendes Logo als Basis
   - Farbe: #f59e0b (Amber/Orange)
   - Export in 3 Varianten

2. **Feature Graphic erstellen** (Canva/Figma)
   - Option A: App-Screenshots-Montage
   - Option B: Gradient + Icon + Tagline
   - Option C: Vor/Nach-Darstellung (Idee → Prototyp)

3. **8 Screenshots aufnehmen**
   - Folge `SCREENSHOT_GUIDE.md`
   - Nutze Android Emulator oder echtes Gerät
   - Füge Captions hinzu (optional)

### Phase 2: Google Play Console Setup (1 Woche)
4. **Developer Account erstellen** ($25 einmalig)
5. **App in Console anlegen**
6. **Alle Texte einfügen** (aus STORE_LISTING_TEXT.md)
7. **Assets hochladen**
8. **Privacy Policy URL eintragen**

### Phase 3: Technisches Setup (1 Woche)
9. **Keystore generieren** für App-Signierung
10. **TWA konfigurieren** (Trusted Web Activity)
11. **AAB bauen** (Android App Bundle)
12. **Google Play Billing** einrichten (Subscriptions)

### Phase 4: Testing (2-4 Wochen)
13. **Internal Testing** (1-2 Wochen)
14. **Closed Alpha** (2-4 Wochen)
15. **Bug-Fixes**

### Phase 5: Launch (1 Woche)
16. **Production AAB hochladen**
17. **Submit for review**
18. **Warten auf Approval** (1-3 Tage)
19. **🎉 LAUNCH!**
