📚 API Master Hilfe

🚀 Erste Schritte mit API Master

  1. API-Key hinzufügen:

    Klicke auf "Key hinzufügen" in der Sidebar und füge deinen ersten API-Key ein.

  2. Keys organisieren:

    Nutze Kategorien (AI, Payment, Maps, etc.) um deine Keys zu organisieren.

  3. Claude AI nutzen:

    Füge einen Claude API-Key hinzu und nutze den AI Assistant direkt in der App!

  4. Sicherheit:

    Alle Keys werden nur lokal in deinem Browser gespeichert - niemals auf einem Server!
