# Changelog

All notable changes to Pure PDF Viewer will be documented in this file.

## [1.0.0] - 2025-10-21

### Added
- Initial release of Pure PDF Viewer
- Core PDF viewing functionality using PDF.js
- Zoom in/out controls (Ctrl +/-)
- Page navigation (arrows, PageUp/PageDown)
- Fit to width functionality
- Modern, elegant UI with dark theme
- Keyboard shortcuts for all major functions
- Setup tool for license management
- Three-tier licensing system (Basic, Pro, Enterprise)
- USB stick distribution tools (Windows & Linux)
- Comprehensive documentation
- Build scripts for Windows, Mac, and Linux
- Monetization infrastructure ready

### Features
- 📄 High-quality PDF rendering
- 🔍 Smooth zoom and navigation
- ⌨️ Full keyboard shortcut support
- 🎨 Beautiful, user-friendly interface
- 💼 Complete sales infrastructure
- 🔐 License key generation system
- 📀 Automated USB copying tools
- 📚 Extensive documentation

### Technical
- Built with Electron 28.0.0
- PDF.js 3.11.174 for rendering
- Electron Builder for packaging
- LocalStorage for license management
- Cross-platform support (Windows, Mac, Linux)

### Documentation
- README.md - Complete overview
- INSTALLATION.md - Setup guide
- MONETIZATION_GUIDE.md - Sales strategies
- LICENSE_SYSTEM.md - License management
- QUICK_START.md - 5-minute start guide
- CHANGELOG.md - Version history

### Tools
- setup-tool.html - License management interface
- KOPIERE_APP_AUF_USB.bat - Windows USB tool
- kopiere-app-auf-usb.sh - Linux/Mac USB tool
