===========================================
  VON DER IDEE ZUM PROTOTYP - START
===========================================

SCHNELLSTART (3 Schritte):

1. ICONS GENERIEREN
   - Öffne: generate-icons.html im Browser
   - Klicke "Icons Generieren"
   - Download alle 8 Icons in den "icons" Ordner

2. API-KEY EINTRAGEN
   - Öffne: index.html mit Editor (Notepad++)
   - Finde Zeile 21: const API_KEY = 'DEIN_API_KEY_HIER';
   - Ersetze mit deinem Claude API-Key
   - Speichern!

3. STARTEN
   - Öffne: index.html im Browser (Chrome/Edge)
   - Fertig! App läuft!

===========================================
ALS APP INSTALLIEREN (PWA)
===========================================

HANDY (Android):
1. Öffne index.html im Chrome Browser
2. Menü (⋮) → "App installieren"
3. Fertig!

HANDY (iPhone):
1. Öffne index.html in Safari
2. Teilen → "Zum Home-Bildschirm"
3. Fertig!

DESKTOP (Windows):
1. Öffne index.html in Chrome/Edge
2. Klicke Install-Icon in Adressleiste
3. Fertig!

===========================================
HÄUFIGE PROBLEME
===========================================

PROBLEM: "Bitte API-Key eintragen"
LÖSUNG:
→ index.html öffnen (Notepad++)
→ Zeile 21: API_KEY eintragen
→ Speichern!

PROBLEM: Icons fehlen
LÖSUNG:
→ generate-icons.html öffnen
→ Alle Icons downloaden
→ In "icons" Ordner speichern

PROBLEM: Offline funktioniert nicht
LÖSUNG:
→ Muss auf HTTPS-Server liegen
→ ODER localhost nutzen
→ Nicht von file:// öffnen
