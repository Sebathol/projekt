🖥️ APP STARTEN (WINDOWS CMD)

📌 OPTION 1: BAT-Datei (EINFACHSTE)

   Doppelklick: TESTE_JETZT.bat
   → Browser öffnen: http://localhost:8000

📌 OPTION 2: CMD Manuell

   1. Windows-Taste drücken
   2. Tippe: cmd
   3. Enter drücken
   4. Befehle eingeben:

   cd C:\Users\DEIN-NAME\Desktop\grow-master-app\www
   python -m http.server 8000

   5. Browser öffnen: http://localhost:8000

📌 OPTION 3: Direkt im Browser (EINFACHSTE)

   1. Öffne Windows Explorer
   2. Navigiere zu: grow-master-app\www\
   3. DOPPELKLICK auf: index.html
   4. App öffnet sich im Browser

   ⚠️ Ohne Server: Manche PWA-Features funktionieren nicht
      → Für volles Erlebnis: Nutze Option 1 oder 2

🔧 PYTHON INSTALLIEREN (falls nicht vorhanden)

Falls "python command not found" Fehler:

1. Gehe zu: https://www.python.org/downloads/
2. Lade "Python 3.xx" herunter (Latest)
3. Installiere Python
   ⚠️ WICHTIG: Hake "Add Python to PATH" an!
4. CMD neu starten
5. Teste: python --version

🛠️ PROBLEMLÖSUNGEN

❌ "python command not found"
   → Python installieren (siehe oben)

❌ "Port 8000 already in use"
   → Nutze anderen Port:
     python -m http.server 8080
   → Dann öffne: http://localhost:8080

❌ "Kann Ordner nicht finden"
   → Nutze Windows Explorer
   → Suche nach: grow-master-app

❌ "App öffnet sich nicht"
   → Stelle sicher, Python läuft (CMD-Fenster offen!)
   → Browser neuladen (F5)
