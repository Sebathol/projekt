📋 Über Pure PDF Viewer

Pure PDF Viewer ist eine moderne, schlanke Desktop-Anwendung zum Anzeigen von PDF-Dateien. Mit diesem Setup-Tool kannst du Premium-Features aktivieren und deine eigene Version für den Verkauf vorbereiten.

🚀 Quick Start

Wechsle zum Tab "Lizenz-Verwaltung" um einen Lizenz-Key zu generieren
Aktiviere Premium-Features im entsprechenden Tab
Nutze "Build & Deploy" um die App zu kompilieren
Verwende die USB-Kopier-Tools für den Vertrieb

Premium-Features

Diese Features können in verschiedenen Lizenz-Levels freigeschaltet werden.

✨ Verfügbare Premium-Features

  • 📝 PDF-Annotation - Notizen und Markierungen hinzufügen
  • 🔄 PDF-Konvertierung - Export zu Word, Excel, Bildern
  • 🔒 Passwort-Schutz - Verschlüsselte PDFs erstellen
  • ✂️ PDF-Bearbeitung - Seiten drehen, löschen, neu anordnen
  • 🖼️ Thumbnail-Ansicht - Schnelle Seitenübersicht
  • 🔍 Erweiterte Suche - Volltextsuche über alle PDFs

Feature-Implementierung

Um diese Features zu implementieren, kannst du Bibliotheken wie pdf-lib oder PDFTron verwenden. Diese Tools sind im Build-Tab dokumentiert.

Build & Deploy

📦 App kompilieren

Führe diese Befehle im Terminal aus:

# Dependencies installieren npm install # App starten (Development) npm start # Windows Build npm run build:win # Mac Build npm run build:mac # Linux Build npm run build:linux # Alle Plattformen npm run build

📀 USB-Stick Vorbereitung

Nutze die mitgelieferten Scripts um die App auf USB-Sticks zu kopieren:

# Windows KOPIERE_APP_AUF_USB.bat # Linux/Mac ./kopiere-app-auf-usb.sh
