📂 Wie funktioniert es?

  1. Erstelle eine JSON-Datei im Ordner werbe-links/
  2. Fülle die Felder aus (id, title, description, url)
  3. Fertig! Die Werbung erscheint automatisch

Beispiel JSON-Datei:

{ "id": "mein-programm-1", "title": "Mein anderes Programm", "description": "Kurze Beschreibung hier", "url": "https://meine-app.de", "priority": 1, "active": true }

✅ Vorteile des Systems

  • Einfach: Nur JSON-Datei kopieren, kein Code nötig
  • Flexibel: Beliebig viele Links (Standard: 10)
  • Dynamisch: Automatisches Laden ohne Server-Neustart
  • Vielseitig: Eigene Apps, Affiliate-Links, externe Werbedienste
  • Priorisierung: Wichtige Links zuerst anzeigen

🎨 Anpassungsmöglichkeiten

  • Farben und Schriftarten
  • Größe und Abstände

🚀 Schnellstart

1. Kopiere das Template 10x:

for i in {1..10}; do cp werbe-links/beispiel-template.json werbe-links/werbeplatz-$i.json done

2. Bearbeite die Dateien:

nano werbe-links/werbeplatz-1.json

3. Prüfe die Links:

curl http://localhost:3000/api/werbe-links | python3 -m json.tool

4. Integriere in HTML:

<!-- CSS einbinden --> <link rel="stylesheet" href="css/werbe-links.css"> <!-- JavaScript einbinden --> <script src="js/werbe-links-ui.js"></script> <!-- Container für Sidebar --> <div id="werbe-links-sidebar"></div> <!-- Container für Footer --> <div id="werbe-links-footer"></div> <!-- Container für Dashboard --> <div id="werbe-links-dashboard"></div>
