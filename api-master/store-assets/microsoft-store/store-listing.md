🚀 API MASTER - REVOLUTIONÄRE API-VERWALTUNG FÜR WINDOWS

🔐 SICHERE PROXY-KEYS
Das Herzstück von API Master: Verwende Proxy-Keys in deinem Code, während deine echten API-Keys verschlüsselt bleiben. Kein Risiko mehr durch exponierte Keys in Git-Repositories!

Wie es funktioniert:
1. Hinterlege deinen Original-API-Key (einmalig, verschlüsselt)
2. Erhalte einen sicheren Proxy-Key (APM_xxx Format)
3. Nutze den Proxy-Key in deinem Code
4. Rotiere Keys jederzeit ohne Code-Änderung!

Beispiel:
❌ Vorher: sk-live-1234567890abcdef (Original exponiert!)
✅ Nachher: APM_abc123def456... (Sicherer Proxy)
