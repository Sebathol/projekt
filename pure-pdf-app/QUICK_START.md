# 🚀 Quick Start Guide

Starte in 5 Minuten mit Pure PDF Viewer!

## ⚡ Schnellstart

### 1. Dependencies installieren (einmalig)

```bash
npm install
```

⏱️ Dauert 2-3 Minuten

### 2. App testen

```bash
npm start
```

Die App öffnet sich automatisch. Teste das Öffnen einer PDF-Datei!

### 3. App kompilieren

**Windows:**
```bash
npm run build:win
```

**Mac:**
```bash
npm run build:mac
```

**Linux:**
```bash
npm run build:linux
```

⏱️ Dauert 3-5 Minuten

Die kompilierte App findest du im Ordner `dist/`

## ❓ Probleme?

### App startet nicht

```bash
# Cache löschen und neu installieren
rm -rf node_modules package-lock.json
npm install
npm start
```

### Build schlägt fehl

**Windows:**
```bash
# Als Administrator ausführen
npm run build:win
```

**Linux:**
```bash
# Build-Tools installieren
sudo apt-get install build-essential
npm run build:linux
```
